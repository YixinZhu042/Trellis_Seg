# VAE v2 parts64：5,000 步后的重建测试

> 发布说明：本页保留实验记录；机器路径已改为占位符，批量图片、GLB、日志和数据缓存不包含在 GitHub 源码中。

`results/seg_vae_v2_parts64_test_20260930/`。

## 结论

128 个留出测试对象的表面 mIoU 为 **95.08%**，面积准确率 **98.63%**。
常规部件数对象表现较好；33–63 部件组只有 8 个对象，平均表面 mIoU 为 **64.92%**，
存在大量小部件遗漏，也有大部件被错标的个例。不能把整体平均分理解为所有对象都已解决。

这次是 **GT 软体素标签 → encoder 后验均值 → decoder/surface head** 的 VAE 重建，
没有 DiT、没有输入图片生成、没有标签平滑或后处理。GT 与预测使用相同相机、几何及颜色。
因此检验的是 VAE 对已有部件标注的压缩/恢复能力，不是图像到分割的端到端生成能力。

- 全部 24 个 rank 各完成 5,000 步；三节点退出码均为 0；检查到的训练 loss 和梯度全为有限值。

- 该权重验证集表面 mIoU **96.12%**；同一步 EMA 为 **95.19%**，没有按测试集重新选权重。

## 128 个测试对象的指标

所有百分比是按对象计算指标后取平均，不是把所有对象面积合在一起统计。

| 指标 | 数值 |
| --- | ---: |
| 表面 mIoU | 95.08% |
| 表面面积准确率 | 98.63% |
| 六视角投影 mIoU | 96.32% |
| 六视角投影准确率 | 99.09% |
| 体素 mIoU | 89.78% |
| 隐藏表面 mIoU | 91.04% |
| 表面小部件召回率 | 89.51% |
| 边界 F1 | 51.71% |
| 孤立错误面积比例 | 0.445% |
| 表面 mIoU 第 10 百分位 | 87.36% |

小部件定义：占单个对象标注表面面积不到 1% 的部件。孤立错误是预测同标签连通区域
小于总标注面积 0.1%，且该区域中的面标签错误；这不等于所有错误，也不表示小三角已消失。
边界 F1 按网格相邻面的部件边界判断，低于面积指标说明边界处仍不够准确。

111/128 个对象表面 mIoU ≥90%；101/128 ≥95%；74/128 ≥99%。
已检查的测试对象面、面积、可见像素标注覆盖均为 100%；这表明解析覆盖完整，不构成
对每个原始语义标签正确性的独立人工证明。

## 失败案例

- `d1d58f05c346470e9805612d562e9dde`：54 部件吉他，表面 mIoU **17.35%**；
  主体大体正确，但大量小部件遗漏/混淆，因此面积准确率仍为 84.45%。
- `251c8125765149c0bd46b3a1a51ff4b6`：60 部件吉他，表面 mIoU **20.93%**，
  面积准确率仅 24.26%；占表面面积 56.72% 的标签 60 召回为 0，图中主体有大片错标。
- `1b6a4e6db7c64b6fa932b189aa694874`：45 部件，表面 mIoU **41.77%**，面积准确率
  96.06%；大部件保留，但多个小部件召回为 0。

后续若继续改进，应先审计高编号/多部件样本的训练频次、输入体素保留情况和每部件召回，
再用验证集做受控训练或容量实验。本轮未改训练配置或继续训练。
