# VAE v2 损失函数详解：从椅子上的小三角到训练日志

本文用“座垫上出现紫色小三角”的例子，解释当前 VAE v2 每项 loss 在做什么、怎样计算，以及怎样判断它的变化。

说明对应 2026-09-23 的实现和默认配置。文中的小型数字例子用于解释计算，并非实测结果；训练统计示例单独标明了时间窗口。修改代码或配置后，应以实际运行目录保存的配置为准。

## 1. 先理解 loss：它是训练时的扣分规则

模型每次看一个对象，先给出自己的预测。训练程序拿预测和正确答案比较，根据不同规则扣分，再调整模型参数，让下次少犯类似错误。

这个“扣分值”就是 loss。反向传播计算的是：如果某个参数略微变化，扣分会怎样变化。优化器据此更新参数。

但分割质量不只包含一种要求。对于椅子，我们至少希望：

- 座垫内部的标签正确。
- 小连接件没有整块消失。
- 一整张座垫面不出现零碎的错误三角。
- 座垫和横杆虽然靠近，仍保持不同标签。
- 从正面、背面、底部看都合理。

只用一种简单的“答错几个位置”规则，可能顾此失彼。V2 因此组合了 8 项重建／表面损失和 1 项 KL 正则。

| 检查方向 | 对应 loss | 通俗问题 |
| --- | --- | --- |
| 单个位置是否正确 | `voxel_ce`、`point_ce`、`surface_ce` | 这个位置到底应该属于哪个部件？ |
| 部件整体是否完整 | `voxel_dice`、`surface_dice` | 这个部件找全了吗？有没有多占别人的区域？ |
| 表面结构是否合理 | `reprojection`、`consistency`、`boundary` | 渲染出来对不对？同一块表面是否破碎？不同部件是否粘在一起？ |
| 压缩表示是否受控 | `kl` | latent 分布是否偏离预设分布过远？ |

这些 loss 是训练目标，不是最终质量的完整定义。它们下降后，仍要用独立验证集的分割指标和三维可视化检查效果。

## 2. 模型在哪些位置预测，正确答案是什么

### 2.1 三种预测不要混淆

```text
原始网格面标签
    │
    ├─ 表面采样、体素化 → 软体素标签 → Encoder → latent
    │                                             │
    │                                          Decoder
    │                                             │
    │                         ┌───────────────────┴─────────────────┐
    │                         │                                     │
    │                    体素类别分数                         局部解码特征
    │                         │                                     │
    │                         └────────── 几何约束的表面头 ──────────┘
    │                                             │
    │                                   每张面内 4 个点的概率
    │                                             │
    │                                      平均四点概率
    │                                             │
    └────────────────────────────────────→ 整张面的概率
                                          与面 GT 比较
```

| 层级 | 模型输出 | 正确答案 |
| --- | --- | --- |
| 体素 | 每个体素的 20 类概率 | 这个体素里的标签分布，可能是软标签 |
| 查询点 | 每张三角面内 4 个点，各自的 20 类概率 | 查询点所在三角面的 GT 标签 |
| 三角面 | 四个查询点概率的平均值 | 这张三角面的 GT 标签 |

几何邻域从输入网格的连接关系、法线和位置建立，不靠 GT 选择邻居。GT 在训练中用于构造重建输入、选择监督样本和计算 loss。解码已有 latent 时不需要 GT 标签。

这里的编号是对象内部的部件编号。本文把某个编号简称为“座垫”或“横杆”只是方便说明，不表示类别 14 在所有对象里都固定代表座垫。GLB 中的颜色也只是标签的显示方式，loss 不在比较红色和紫色的 RGB 距离。

### 2.2 logits、概率和最终标签的区别

网络先输出 logits，也就是各类别的原始分数。softmax 把它们转换成非负且总和为 1 的概率。

例如只考虑座垫和横杆两类，分数是 `[2, 0]`，经过 softmax 后概率约为 `[0.881, 0.119]`。

训练使用概率和 logits，而不是先把它们变成一个整数标签。否则，以下两种预测都会只是“座垫”，无法细分它们的可靠程度：

```text
预测 A：座垫 51%，横杆 49%
预测 B：座垫 99%，横杆  1%
```

两者 argmax 相同，但 B 对正确标签更有把握，CE 通常更低。最终导出 GLB 时才取 argmax，给每张面赋一个确定标签。

### 2.3 标签 0 如何处理

当前数据中，0 表示未标注，不应被当作一个真实语义部件。

计算体素重建监督时，先把 GT 分布的第 0 类置为 0，再把剩余类别归一化。例如：

```text
原始 GT：未标注 50%，座垫 30%，横杆 20%
用于重建监督的 GT：座垫 60%，横杆 40%
```

如果一个体素全部未标注，就不计算它的重建损失。面监督和配对监督也排除 GT 为 0 的位置。

注意：预测端仍然保留 20 类 softmax，包括类别 0。在有标注位置把概率分给类别 0，会挤占正确类别的概率，仍然受到惩罚。忽略的是“没有正确答案的位置”，不是允许把有标注区域随便预测成 0。

### 2.4 本文使用的符号

| 符号 | 含义 |
| --- | --- |
| $v$ | 一个有效体素 |
| $f$ | 一次抽到的三角面；同一张面可重复抽到 |
| $j$ | 面内第几个查询点，取 1 到 4 |
| $c$ | 部件类别编号 |
| $q_{v,c}$ | 体素的软 GT 概率 |
| $p_{v,c}$ | 模型的体素预测概率 |
| $p_{f,j,c}$ | 面内查询点的预测概率 |
| $P_{f,c}$ | 聚合后的整张面预测概率 |
| $y_f$ | 三角面 GT 标签 |
| $A_f$ | 三角面的面积 |
| $s_f$ | 训练中抽到这张面的概率 |
| $H_f$ | 这张面在六视图中累计覆盖的像素数 |

所有对数都是自然对数。`1e-8`、`1e-12` 等很小的常数用于防止除零和数值溢出，不是额外的监督目标。

## 3. `voxel_ce`：每个体素应该是什么标签

### 3.1 最简单的情况：只有一个正确标签

若 GT 是座垫，一个体素的普通 CE 为：

$$
\ell_v=-\log p_{v,\text{座垫}}
$$

它只问：你给正确答案多少概率？

| 预测为座垫的概率 | CE，约值 | 含义 |
| ---: | ---: | --- |
| 0.99 | 0.010 | 对正确答案很有把握 |
| 0.90 | 0.105 | 大体可靠 |
| 0.50 | 0.693 | 很犹豫 |
| 0.10 | 2.303 | 大部分概率给了错误答案 |
| 0.01 | 4.605 | 很确信地答错，惩罚很大 |

这也是个别困难对象容易出现 loss 尖峰的原因：高置信度错误会受到较大惩罚。

### 3.2 混合体素使用软标签

假设一个体素收到 7 个座垫采样点、3 个横杆采样点。V2 保存 `[0.7, 0.3]`，不提前多数投票成 `[1, 0]`。

不考虑类别权重时：

$$
\ell_v=-0.7\log p_{v,\text{座垫}}-0.3\log p_{v,\text{横杆}}
$$

| 预测概率：座垫／横杆 | 普通软 CE，约值 |
| --- | ---: |
| 0.7 / 0.3 | 0.611 |
| 0.9 / 0.1 | 0.765 |
| 0.5 / 0.5 | 0.693 |

匹配 70%／30% 的预测比强行偏向座垫更合适。这里的 70%／30% 是采样标签比例，不是模型“对答案没把握”的标注。

### 3.3 再给小部件增加权重

当前对象中类别 $c$ 的有效体素数量用软计数表示：

$$
N_c=\sum_v q_{v,c}
$$

对实际出现的类别计算平均数量 $\overline N$，类别权重为：

$$
w_c=\operatorname{clip}\left(\sqrt{\frac{\overline N}{N_c}},\;0.25,\;5\right)
$$

数量少的部件通常权重大，数量多的部件权重小。取平方根和限制范围，是为了避免一个极小或噪声部件完全主导训练。这里的权重是每个对象内部计算的，不是整个数据集的类别频率表。

举例：大部件有 1000 个体素，小部件有 10 个，平均为 505。权重大约是：

```text
大部件：sqrt(505 / 1000) ≈ 0.71
小部件：sqrt(505 /   10) ≈ 7.11，截断为 5
```

小部件单个体素受到更强关注，但并没有做到两个部件总权重完全相等：大部件总权重约 710，小部件约 50。这是温和地缓解不平衡，不是强制完全平衡。

最终实际计算：

$$
L_{\text{voxel CE}}=
\frac{-\sum_{v,c}w_cq_{v,c}\log p_{v,c}}
{\sum_{v,c}w_cq_{v,c}}
$$

### 3.4 这项 loss 的作用与局限

它负责体素层面的分类重建，帮助保留细小零件的信息。但体素内仍只有一个位置和一组特征；保留混合分布不等于把两个部件在空间上拆开。

还有两个容易误解的点：

- 软 GT 的 CE 即使预测匹配也可能大于 0，因此不能把所有非零 CE 都当作错误。
- 加上类别权重后，这一项单独优化时偏好的分布与 $w_cq_{v,c}$ 成比例，不再严格等于原始 $q_{v,c}$。保留软标签和提高小部件权重之间存在明确的权衡。

代码对应：`masked_soft_target()`、`balanced_soft_ce()`。

## 4. `voxel_dice`：每个部件整体有没有被找全

### 4.1 为什么有 CE 还要 Dice

CE 从一个个位置出发检查答案。Dice 则把某个部件作为整体，检查预测区域和真实区域重叠多少。

假设 99% 的体素属于大部件，1% 属于小连接件。把大部件做好、小连接件全丢掉，总体准确率仍有 99%。按部件平均的 Dice 会专门给连接件记一次很差的成绩。

### 4.2 实际公式

先给有效体素等权，再把权重归一化为 $\alpha_v=1/N$。对部件 $c$：

$$
D_c=\frac{2\sum_v\alpha_v p_{v,c}q_{v,c}+\epsilon}
{\sum_v\alpha_v p_{v,c}+\sum_v\alpha_v q_{v,c}+\epsilon}
$$

最后对 GT 中出现的有效部件平均：

$$
L_{\text{voxel Dice}}=\frac{1}{K}\sum_c(1-D_c)
$$

忽略微小的 $\epsilon$ 时，分子分母中的公共归一化系数可以约掉，所以也经常看到直接对体素求和的写法。

### 4.3 一个硬标签近似例子

某部件真实有 100 个位置，模型预测有 90 个，其中 80 个正确重叠：

```text
Dice = 2 × 80 / (100 + 90) ≈ 0.842
Dice loss = 1 - 0.842 ≈ 0.158
```

少找了真实区域，或多占了别人的区域，都会降低 Dice。这解释了它为什么同时约束漏分和误分。

真实训练使用软概率，不先取硬标签。每个有效部件对最终平均值占一个份额，但这不保证它们对所有参数的梯度影响完全相同。

### 4.4 不要把 soft Dice 当成 mIoU

评估 mIoU 通常先取 argmax，再按交集／并集计算。这里的 Dice 使用连续概率，是便于训练的代理目标，两者不能直接换算。

对软 GT，还有一个细节：本实现采用 $p\times q$ 的重叠。如果只有一个混合位置，GT 和预测都为 `[0.7, 0.3]`，不计 $\epsilon$，两个类别的 Dice 分别为 0.7、0.3，而不是 1。也就是说，“完全匹配软分布”未必使这一项等于 0；它与 CE 并非完全相同的目标。

代码对应：`macro_dice()`，体素调用中所有有效体素等权。

## 5. 表面采样权重：先看懂后面几项为什么要除以抽样概率

### 5.1 为什么不每一步遍历所有网格面

对象可能有数万甚至数十万张面。为控制训练时间与显存，默认每个对象抽取 2048 张面计算主要表面损失，每张面查询 4 个点。抽样是有放回的，同一面可能出现多次。

另外还会加入面配对的端点计算关系损失，所以实际查询的面条目可能多于 2048。配对端点不会自动混入主要表面 CE／Dice 的统计。

### 5.2 两种抽样分布各占一半

设对象有效标注表面总面积为 $A_{\text{总}}$，面 $f$ 所属部件面积为 $A_{y_f}$，有效部件数为 $K$：

$$
s_f=0.5\frac{A_f}{A_{\text{总}}}+0.5\frac{A_f}{K A_{y_f}}
$$

第一项按全局面积抽样：面积大的区域获得更多样本。

第二项先让各部件获得相同总概率，再在部件内部按面积分配。这样小部件也有机会经常被选中。

### 5.3 为什么要用“面积除以抽样概率”

用一个极端例子说明：一张大面面积 9，一张小面面积 1，但为了训练小部件，把两张面都按 50% 概率抽样。

如果抽到后直接等权，大面和小面各占一半，统计就不再反映真实面积。

给它们分别乘上“面积／抽样概率”：

```text
大面权重 = 9 / 0.5 = 18
小面权重 = 1 / 0.5 =  2
```

就能在统计上恢复 9:1 的面积关系。代码里叫 `surface_importance`：

$$
a_f=\frac{A_f}{s_f}
$$

它不是小部件奖励，而是对抽样方式的修正。当前损失使用“加权总和／权重总和”的有限样本估计，不能称为每一步精确无偏的全网格损失；尤其 Dice 本身也是比值。

### 5.4 小部件奖励另外计算

根据抽中的面估计各部件面积：

$$
\widehat A_c=\sum_{f:y_f=c}a_f
$$

再计算部件平衡系数：

$$
w_c^{\text{surface}}=
\operatorname{clip}\left(\sqrt{\frac{\overline{\widehat A}}{\widehat A_c}},\;0.25,\;5\right)
$$

最终小部件加权后的面权重：

$$
b_f=a_f w_{y_f}^{\text{surface}}
$$

因此这里有三个不同操作：

| 操作 | 目的 |
| --- | --- |
| 更频繁地抽到小部件 | 增加小部件被训练看到的机会 |
| 除以抽样概率 | 修正抽样造成的面积或像素统计偏差 |
| 乘以部件平衡系数 | 明确提高小部件错误的重要程度 |

代码对应：`face_sampling_probability()`、`training_queries()`，以及 `reconstruction_losses()` 中的 `part_mass`、`balance`。

## 6. `point_ce`：要求面内四个点分别判断正确

每张三角面内部有一个中心点，以及三个更靠近顶点的内部点。不是在三个顶点上直接查询，也不是每轮随机选择这四个位置。

每个查询点的 GT 都是所在面的标签。对面 $f$ 的第 $j$ 个点：

$$
\ell_{f,j}=-\log p_{f,j,y_f}
$$

实际用小部件加权后的 $b_f$ 平均：

$$
L_{\text{point CE}}=
\frac{\sum_f b_f\sum_{j=1}^4(-\log p_{f,j,y_f})}
{4\sum_f b_f}
$$

它关心的是：四个位置各自可靠不可靠。即使其他三个点能够挽救整张面的最终标签，也不能放任某个查询点一直严重错判。

举例，面 GT 是座垫，四个点给座垫的概率为：

```text
0.1、0.9、0.9、0.9
```

四点平均 CE 约为：

```text
(-log 0.1 - log 0.9 - log 0.9 - log 0.9) / 4 ≈ 0.655
```

虽然大部分点预测正确，第一个点的严重错误仍然会受到明确惩罚。

局限：当前默认一张三角面内部 GT 标签统一。如果原始标注确实需要在同一张面内部划分两个部件，这种表示和监督本身就不足，需要更细的表面表示。

## 7. `surface_ce`：要求最终赋给整张面的标签正确

### 7.1 先聚合四点概率

$$
P_{f,c}=\frac14\sum_{j=1}^4p_{f,j,c}
$$

实现用 `logsumexp(log_softmax(...)) - log(4)` 得到它的对数，主要是为了数值稳定。它等价于先算四点概率再求平均。

不要把它理解为“投票选出四个标签中最多的标签”。概率的大小也参与聚合。

### 7.2 再计算最终面的 CE

$$
\ell_f=-\log P_{f,y_f}
$$

当前权重为：

$$
u_f=0.5a_f+0.5b_f
$$

最终：

$$
L_{\text{surface CE}}=
\frac{\sum_fu_f(-\log P_{f,y_f})}{\sum_fu_f}
$$

这是把普通面积权重和小部件加权混合后，进行一次归一化；不严格等于“分别算两个独立 CE，再各乘 0.5”。

### 7.3 它为什么不能被 point CE 完全替代

继续使用四点正确类别概率 `[0.1, 0.9, 0.9, 0.9]`：

```text
平均概率 = 0.7
surface CE = -log 0.7 ≈ 0.357
point CE ≈ 0.655
```

如果四个点都是 0.7，surface CE 仍约 0.357，但 point CE 也变成约 0.357。

也就是说：

- surface CE 看最终集体答案，同样的平均概率得到同样的结果。
- point CE 还能区分“四个点都一般可靠”和“有一个点严重错误”。

对座面小三角来说，surface CE 直接惩罚最终整面错色；point CE 同时训练面内局部预测不要失控。

传入 `weighted_ce()` 的面输入已经是对数概率。由于这些概率和为 1，再经过交叉熵内部的归一化，仍等价于取正确类别的负对数。

## 8. `surface_dice`：整块部件在网格表面是否完整

它沿用 Dice 思路，但位置变成三角面，权重体现面积。

把抽样修正权重归一化：

$$
\alpha_f=\frac{a_f}{\sum_fa_f}
$$

对部件 $c$：

$$
D_c^{\text{surface}}=
\frac{2\sum_f\alpha_fP_{f,c}\mathbf1[y_f=c]+\epsilon}
{\sum_f\alpha_fP_{f,c}+\sum_f\alpha_f\mathbf1[y_f=c]+\epsilon}
$$

最后对抽样 GT 中出现的有效部件取平均：

$$
L_{\text{surface Dice}}=\frac1K\sum_c(1-D_c^{\text{surface}})
$$

其中 $\mathbf1[y_f=c]$ 表示“如果这张面的 GT 就是类别 $c$，取 1，否则取 0”。

它同时关心两类问题：座垫有没有缺块，以及座垫有没有错误侵占横杆区域。小部件即使面积不大，在部件平均时也不会直接被大座面淹没。

面积加权还减少了网格三角剖分不均匀带来的影响。一片区域拆成很多小三角，不应该只因为三角数量更多，就获得不合理的大权重。

局限：这仍是抽样统计。如果某个极小部件本次未被抽到，就不在本次该项的部件平均中。部件均衡采样可以缓解，但不是保证每轮覆盖全部部件。

## 9. `reprojection`：从六个相机看，分割结果是否正确

### 9.1 体积、面积和像素数不是同一种权重

一张座垫顶面可能从顶部看覆盖很大一块图像，但从侧面看只是一条细线。另一张隐藏面有实际面积，却在六个视图里都看不到。

重投影损失使用“这张面在图像中出现了多少像素”来计权，关注可见的视觉错误。

设面 $f$ 在六视图中累计覆盖 $H_f$ 个像素。例如顶部 500 个、侧面 200 个，那么 $H_f=700$。多视角重复看到同一面会累计计入。

### 9.2 计算方式

$$
h_f=\frac{H_f}{s_f}
$$

$$
L_{\text{reprojection}}=
\frac{\sum_fh_f(-\log P_{f,y_f})}{\sum_fh_f}
$$

只使用有有效 GT 且像素数大于 0 的面。如果本次抽样没有有效可见面，这项 loss 返回 0。

### 9.3 为什么不需要每步真正渲染

当前训练不改变网格位置，所有面、相机和遮挡关系固定。某个像素由哪张面负责，可以预先算好。

同一张面所有像素使用相同的面预测，所以把这张面的 CE 重复计算 700 次，与乘以 700 是同一回事。预先保存面像素计数就能避免每步运行渲染器。

这里仅对抽样面做采样概率修正后的加权估计，不是每步遍历六张完整图像。

### 9.4 它与 surface CE 的区别

| 情况 | surface CE | reprojection |
| --- | --- | --- |
| 大面积且清晰可见的座面 | 关注 | 关注 |
| 有面积但完全隐藏的座垫底面 | 仍可通过抽样获得监督 | 不贡献像素损失 |
| 面积相近但成像大小不同的两张面 | 面积权重近似 | 像素多的一张影响更大 |

因此重投影不能替代三维表面监督。单看六视图很好看，也不能证明隐藏结构分得正确。

## 10. `consistency`：同一部件内部不要出现无故的标签跳变

### 10.1 为什么需要比较相邻面

有时两张相邻座垫面分别预测成：

```text
面 A：座垫 95%，横杆  5%
面 B：座垫 10%，横杆 90%
```

两个面真实都属于座垫，但预测在接缝处突然改变。这就是错误碎片和伪边界的一种来源。

CE 会分别告诉两张面“你应该是座垫”。一致性还增加一个关系约束：“这两个本来属于同一块表面的预测，应该相互协调。”

### 10.2 使用完整概率分布，而不只比较 argmax

对两张面概率 $P_a,P_b$，先计算中间分布：

$$
M=\frac{P_a+P_b}{2}
$$

再计算 Jensen–Shannon 散度，简称 JS：

$$
\operatorname{JS}(P_a,P_b)=
\frac12\sum_cP_{a,c}\log\frac{P_{a,c}}{M_c}
+\frac12\sum_cP_{b,c}\log\frac{P_{b,c}}{M_c}
$$

可以把它理解成“这两个概率分布有多不一样”。完全相同为 0。对于精确归一化的概率，JS 的理论上界为 $\log 2\approx0.693$。实现对很小的概率做截断以保证数值稳定。

二分类示例：

| 面 A | 面 B | JS，约值 |
| --- | --- | ---: |
| `[0.9, 0.1]` | `[0.9, 0.1]` | 0 |
| `[0.9, 0.1]` | `[0.1, 0.9]` | 0.368 |

### 10.3 根据法线减弱锐角处的约束

设两面的单位法线为 $n_a,n_b$：

$$
g_{ab}=\max(0,n_a\cdot n_b)
$$

法线点积就是夹角余弦：

| 法线夹角 | 几何权重，约值 |
| ---: | ---: |
| 0°，朝向相同 | 1 |
| 60° | 0.5 |
| 90° | 0 |
| 大于 90° | 0 |

最终只对 GT 相同的配对计算：

$$
L_{\text{consistency}}=
\frac{\sum_{(a,b):y_a=y_b}g_{ab}\operatorname{JS}(P_a,P_b)}
{\sum_{(a,b):y_a=y_b}g_{ab}}
$$

没有有效配对或权重总和为 0 时返回 0。

### 10.4 为什么一致性低不等于标签正确

如果两张座垫面都被预测成横杆，它们也可以很一致。甚至两张面都给出模糊的均匀概率，一致性 loss 也可以为 0。

因此这项只负责“减少不协调”，正确类别必须由 CE 和 Dice 决定。

它也是训练损失，不是推理结束后把邻居强行改成同一标签的后处理。当前实现只对所选配对施加约束，没有显式保证整张网格连通、没有直接删除小岛，也不是完整的图传播网络。

## 11. `boundary`：不同部件的概率分布不要粘在一起

### 11.1 名字容易误导：它不是边界 F1 的直接公式

代码中的 `boundary` 实际是“不同 GT 部件的面之间，概率重叠是否过大”。它不会直接测量边界偏移了多少毫米，也不直接计算边界像素的 precision/recall。

对于真实属于不同部件的两张面，概率重叠为：

$$
o_{ab}=\sum_cP_{a,c}P_{b,c}
$$

一个直观解释：假设按各自分布随机抽一个类别，$o_{ab}$ 就是两次抽到同一类别的概率。

GT 不同，就希望这种重叠较低：

$$
L_{\text{boundary}}=
\operatorname{mean}_{(a,b):y_a\ne y_b}
\left[-\log(1-o_{ab})\right]
$$

实现将重叠截断在 `[1e-6, 1-1e-6]` 内，避免 `log(0)`。因此连完美分离也会有约 $10^{-6}$ 的数值下限。

### 11.2 几个非常关键的例子

| 面 A 的概率 | 面 B 的概率 | 重叠 | 分离 loss，约值 |
| --- | --- | ---: | ---: |
| `[0.9, 0.1]` | `[0.1, 0.9]` | 0.18 | 0.198 |
| `[0.9, 0.1]` | `[0.9, 0.1]` | 0.82 | 1.715 |
| `[0.99, 0.01]` | `[0.99, 0.01]` | 0.9802 | 3.922 |

GT 明明属于不同部件，却越来越确信地预测成同类，惩罚就越来越大。

反过来，它也存在一个局限：20 类都给 0.05 的均匀预测，两张面的重叠只有 0.05，loss 约为 0.051。这个数甚至比第一行更低，但均匀预测显然不是好的分割。

另外，只要两个面各自预测成不同类别，即使两者都不符合 GT，这项也可能很低。所以它必须和分类损失配合，不能单独判断标签质量。

### 11.3 面配对从哪里来

候选配对包含：

1. 网格共享边两侧的相邻面。
2. 几何上接近、但属于不同连通分量的面。

第二种情况是为了解决“座垫和横杆并没有共享边，但彼此非常接近”。这把椅子不同部件之间没有 GT 跨部件共享边，只有第一种配对时就会漏掉许多分离约束。

邻近配对从表面锚点的近邻中产生，距离上限默认约为 8 个体素单位，并不是穷举所有近距离面。

候选建好后，GT 只用于判断每一对应该“一致”还是“分离”。默认最多抽约 512 对同标签、512 对不同标签；不足时使用更少配对。没有不同 GT 配对时，`boundary` 返回 0。

同标签配对只计算一致性，不会被这一分离项推动分开；不同标签配对只计算分离，不会被一致性项强行平滑。这是避免抹掉真实部件边界的关键。

### 11.4 为什么 boundary 上升而边界 F1 可能改善

训练项关注软概率，评估 F1 关注最终 argmax 标签在规定邻接关系上的变化，两者关注对象不同。

例如大部分边界位置已经分对，但少量剩余错误变得更高置信度，平均分离 loss 可能上升，而硬标签边界 F1 仍在提升。训练中的配对抽样变化也会带来波动。

因此看到 `boundary` 上升时应检查：重复出现的同一对象是否也上升、错误是否集中在少数对象、验证集的分离率/伪边界率是否恶化。它是需要追踪的信号，不是单独的停训判据。

## 12. `kl`：约束 latent 分布，而不是直接修复三角面

### 12.1 Encoder 为什么输出均值和方差

VAE encoder 不只输出一个确定向量，而是给每个 latent 位置的每一维输出：

- 均值 $\mu$：这个维度通常取什么值。
- 对数方差 $\log\sigma^2$：这个值允许多大波动。

需要随机采样时：

$$
z=\mu+\sigma\epsilon,\qquad \epsilon\sim\mathcal N(0,1)
$$

确定性重建则直接取 $z=\mu$。

### 12.2 KL 具体怎么计算

当前实现比较 posterior 高斯分布与标准高斯：

$$
L_{\text{KL}}=
\frac12\operatorname{mean}\left(
\mu^2+\exp(\log\sigma^2)-1-\log\sigma^2
\right)
$$

这里对 latent 位置和通道共同取平均，不是把所有通道的 KL 直接相加。

单个维度的例子：

| $\mu$ | $\sigma^2$ | 该维度 KL |
| ---: | ---: | ---: |
| 0 | 1 | 0 |
| 1 | 1 | 0.5 |
| 0 | 0.25 | 约 0.318 |

它鼓励均值、方差不要偏离预设分布太远。重建需要保留信息，KL 则限制表示分布，两者需要平衡。KL 太强可能牺牲细节；很小的 KL 也不能单独证明 latent 对后续 DiT 好学。

### 12.3 当前如何逐渐加入 KL

$$
\beta(s)=10^{-5}\cdot
\min\left(1,\frac{\max(0,s-1000)}{2000}\right)
$$

| 阶段 | Encoder 输出如何使用 | KL 系数 |
| --- | --- | --- |
| 第 1～1000 步 | 使用均值，不采样噪声 | 0 |
| 第 1001 步 | 开始采样 posterior | $5\times10^{-9}$ |
| 第 2000 步 | 采样 posterior | $5\times10^{-6}$ |
| 第 3000 步及之后 | 采样 posterior | $10^{-5}$ |

采样噪声是在第 1001 步开始使用，不是像 KL 系数那样从 0 慢慢放大。这时重建 loss 可能因为输入 latent 有噪声而上跳，不一定是 KL 标量本身导致。

日志仍会记录原始 KL，即使当前系数为 0。比如 KL=6.7：

```text
第 900 步：总 loss 中的贡献 = 6.7 × 0 = 0
达到最大系数后：贡献 = 6.7 × 0.00001 = 0.000067
```

不能因为原始 KL 比 CE 大很多，就认为它主导了训练。也不能认为很小的加权标量一定没有梯度影响。

## 13. 九项怎样组成一个总 loss

默认配置实际使用：

$$
\begin{aligned}
L={}&L_{\text{voxel CE}}
+0.25L_{\text{voxel Dice}}\\
&+0.5L_{\text{point CE}}
+0.5L_{\text{surface CE}}
+0.25L_{\text{surface Dice}}\\
&+0.25L_{\text{reprojection}}
+0.1L_{\text{consistency}}
+0.1L_{\text{boundary}}
+\beta(s)L_{\text{KL}}
\end{aligned}
$$

这里的系数才决定各项如何进入最终标量。日志的 `voxel_ce` 等字段保存的是已经完成其内部加权/平均、但尚未乘以上述总体系数的值。

比如 `voxel_ce` 已经包含类别权重；`surface_ce` 已经包含采样修正和面积/部件混合权重。说它们是“原始 loss”，只是相对于最外层总体系数而言，不代表内部完全没有加权。

### 13.1 用一组实际历史统计还原总 loss

下面取自此前对本轮训练第 863～962 步、40 个 rank 的均值分析，是历史窗口示例，不表示当前实时状态：

| 日志字段 | 窗口平均值 | 外层系数 | 对总 loss 的贡献，约值 |
| --- | ---: | ---: | ---: |
| `voxel_ce` | 0.169158 | 1.0 | 0.169158 |
| `voxel_dice` | 0.140645 | 0.25 | 0.035161 |
| `point_ce` | 0.089170 | 0.5 | 0.044585 |
| `surface_ce` | 0.070284 | 0.5 | 0.035142 |
| `surface_dice` | 0.078796 | 0.25 | 0.019699 |
| `reprojection` | 0.047728 | 0.25 | 0.011932 |
| `consistency` | 0.005019 | 0.1 | 0.000502 |
| `boundary` | 0.276982 | 0.1 | 0.027698 |
| `kl` | 6.700621 | 0 | 0 |
| **`loss`** | — | — | **约 0.343877** |

这是多项不同目标的组合，不是一个准确率或错误百分比。总 loss=0.34 不意味着 34% 的面错了。

### 13.2 标量贡献和梯度贡献不是同一回事

某项贡献 0.01、另一项贡献 0.1，并不表示后者对所有参数的更新影响一定是前者 10 倍。梯度还取决于预测值、公式的局部斜率和网络路径。

因此不能只因为某项数值较小就直接放大它，也不能因为某项数值较大就认定它压制了其他项。若要分析目标之间是否冲突，应单独测量梯度、做损失消融，并观察验证质量。

## 14. 哪些参数会被这些 loss 更新

| 损失 | 直接监督位置 | 梯度可以到达 |
| --- | --- | --- |
| 体素 CE / Dice | decoder 体素输出 | decoder、encoder |
| 点 CE、面 CE / Dice、重投影 | 表面头输出 | 表面头、decoder、encoder |
| 一致性、分离 | 配对的面概率 | 表面头、decoder、encoder |
| KL | encoder 的均值/方差 | encoder |

几何位置、法线、邻接索引和面像素计数在这里是固定输入，不作为需要优化的参数。最终 argmax、GLB 颜色、评估 mIoU 也不在这条反传链上。

这些约束的关系可以理解为：分类项指出正确答案，Dice 检查部件覆盖，一致性和分离项检查预测之间的关系。它们可能互补，也可能在有噪声、重复面冲突或混合标签时产生不同方向的要求，需要实验确定权衡。

## 15. 怎样正确读训练日志

### 15.1 单卡日志不是全局平均

日志路径为 `logs/seg_vae_v2/train_rankXXXX.jsonl`。每一行记录该 rank 当前优化步的损失；如果配置了梯度累积，则先对该 rank 的 microbatch loss 取平均。

当前默认每 GPU 每 microbatch 一个对象，`accumulate=1`。40 个 rank 同一步会处理不同对象，单卡 loss 相差很大完全可能。

DDP 会平均各 rank 的梯度；但 JSONL 中的 loss 没有自动做 40 卡平均。判断趋势时应把同一步的多个 rank 汇总，再对一段时间求均值或中位数。

### 15.2 一行日志中各字段的含义

| 字段 | 含义 | 注意事项 |
| --- | --- | --- |
| `step` | 已执行的优化步编号 | 不是对象数量，也不是 epoch 数 |
| `seconds` | 本次运行的累计耗时 | 断点恢复后会重新起计时；中间包含保存和验证开销 |
| `loss.voxel_ce` 等 | 本 rank 各项损失 | 还没乘总 loss 外层系数 |
| `loss.loss` | 本 rank 的加权总损失 | 不直接等于分割错误率 |
| `grad_norm` | 梯度裁剪前的总范数 | 大于阈值不代表裁剪后的更新也这么大 |
| `kl_weight` | 当前 KL 系数 | 读 KL 必须一起看它 |

### 15.3 正常波动与需要关注的现象

| 观察到的现象 | 可能含义 | 应同时检查 |
| --- | --- | --- |
| 某个 rank 突然 loss 很高 | 碰到困难样本或标签冲突 | 是否只是一两个对象，随后是否恢复 |
| 平均 CE / Dice 持续下降 | 重建目标正在改善 | 验证集是否也改善 |
| 总 loss 降，但 boundary 上升 | 剩余分离错误、置信度变化、样本配对变化 | 分离率、伪边界率和同对象复测 |
| consistency 很低 | 邻近面概率相似 | 是否一起分错或一起变模糊 |
| reprojection 很低 | 可见区域监督较好，或可见样本少 | 隐藏表面和有效像素数 |
| 第 1001 步附近 loss 上跳 | 开始 posterior 采样，训练条件改变 | 一段时间后能否稳定，下一轮验证是否退化 |
| 梯度范数持续增大或出现 NaN/Inf | 数值不稳定风险 | 数据异常、学习率、各项 loss 与梯度 |

建议把两次出现的同一对象也配对比较，减少“刚好抽到更简单对象”的误判。但其查询点采样和 posterior 噪声仍可能不同，所以单个对象的一次涨跌不够说明问题。

### 15.4 为什么不能只追求训练 loss 降到最低

模型可能记住训练对象，训练 loss 降了而未见对象表现变差。不同 loss 系数或不同监督表示下，总 loss 的尺度也不一样，不能直接跨实验比大小。

当前 checkpoint 用独立 validation 选择，优先看表面 mIoU，再看小部件召回率和孤立错误面积。测试集不参与选型。最终仍需检查训练没直接优化到的行为，例如严重局部错分、隐藏区域错误和较差对象的尾部表现。

## 16. 用一个座面错误串起全部损失

假设一张真实座垫三角面，在最终 GLB 中被错误染成横杆颜色：

1. 如果附近体素已经被分错，`voxel_ce` 会降低正确标签概率过低的情况；`voxel_dice` 检查座垫及横杆整体的体素覆盖。
2. 如果四个面内查询点有一个严重错误，`point_ce` 会直接惩罚那个点。
3. 如果四点聚合后整面仍然错误，`surface_ce` 会惩罚最终面答案；`surface_dice` 同时检查这块错误对两个部件覆盖的影响。
4. 如果这张面从顶部看很明显，`reprojection` 会按可见像素强调它的视觉影响；若只在隐藏底面，则依靠三维表面监督。
5. 如果它与周围同 GT 座垫面概率差别很大，`consistency` 会惩罚这种不协调。
6. 如果它与邻近真实横杆面的概率变得过于相同，`boundary` 会惩罚两个不同部件的粘连。
7. `kl` 不直接识别这张错面，而是控制产生这些预测的 latent 分布。

不保证每个错误都会同时触发全部项：有些面没有有效邻接配对，有些隐藏面没有像素贡献，有些错误区域可能内部高度一致。多个目标组合，是为了覆盖不同盲点。

## 17. 常见误解

**“Dice loss 就是 1 减 mIoU？”** 不是。公式不同，而且这里使用软概率；mIoU 通常使用最终硬标签。

**“软 GT 预测完全匹配，所有重建 loss 就都为 0？”** 不是。软 CE 有目标熵，类别加权还会改变最优偏好；当前 soft Dice 在混合目标上也不一定以 0 为下限可达值。

**“point CE 和 surface CE 是重复算四遍同一件事？”** 不是。一个约束每个点，一个约束四点聚合的结果。四点平均正确不代表四个点都可靠。

**“相邻面一致性会把座垫和横杆平滑成一块？”** 当前只在 GT 相同的训练配对上施加一致性；GT 不同的配对使用分离项。几何邻接不等于同一语义部件。

**“boundary 越低，边界一定越准确？”** 不是。模糊分布或两个不同但都错误的类别也可能让分离 loss 较低；需要 CE 和实际边界指标共同判断。

**“日志 boundary 为 0，代表这个对象的所有边界完美？”** 不一定。它可能没有抽到任何有效异标签配对。

**“KL=6.7，比总 loss=0.34 大，程序是不是算错了？”** 不一定。KL 要乘当前系数；前 1000 步其系数为 0。

**“梯度裁剪和 EMA 也是 loss？”** 不是。裁剪限制更新前的梯度范数；EMA 平滑模型权重，它们不直接构成上述总 loss。

**“这些项已经能保证没有小三角？”** 不能。它们是减少错误的训练机制。单点或多点都可能预测错，GT 也可能冲突，最终一面一标签的表示还有限制。需要用独立验证与可视化确认实际收益。
