## 结论

128 个测试对象的 DiT 表面 mIoU **83.58%**，投影 mIoU **88.51%**。
少部件对象已能生成较好的结果，但多部件、小部件、隐藏表面仍明显偏弱。
同样本、同 VAE 的重建表面 mIoU 为 **95.96%**，相差 **12.38 个百分点**。
VAE 的重建改善没有自动转化为 DiT 的同等改善，两个吉他依然明显失败。

VAE 重建在这里是参考，不是每个样本必须满足的严格数学上界。

## 推理协议和解释范围

- 使用训练时确定的 128 个 test 对象，另加 3 个 train 历史诊断对象和 3 个 validation 复算对象。
  只有 test 对象计入主要指标，共推理 **134** 个对象。
- 条件是 **正确 GT 生成的六视图分割 latent + shape 几何条件**，使用已知网格几何。
  不是外部 API 分割图/真实照片输入的端到端测试，也不是生成新网格形状。
- DiT 从纯 Gaussian noise 开始，20 步 Euler，不使用 CFG。种子为
  `20260930 + int(instance[:8], 16)`，与训练期间验证一致。
- GT 目标 latent 的值不用于 DiT 初始值或条件；单独解码缓存的 GT 后验均值作为 VAE 参考。
- 原始部件编号评分，无 Hungarian 标签匹配，无平滑/连通域清理或其他后处理。
- 每对象仅一个固定种子，未测多种子方差或 50 步采样；不从测试结果挑选采样设置。
- 三个 validation 对象复算的表面、投影、体素、隐藏面指标与已保存训练验证记录差异全为 **0**。
- 128 个 VAE 参考结果与 2026-09-30 的置换续训 VAE 测试对应指标差异全为 **0**。
- 测试数据此前参与开发诊断，历史初始化模型也可能见过部分数据；本次是固定开发回归评估，
  不能表述为全新独立盲测泛化结果。

先按对象计算指标，再对有效指标取平均；不是按所有对象合并面积计算。

| 指标 | DiT 生成 | 同一 VAE 重建参考 |
| --- | ---: | ---: |

| 表面面积准确率 | 93.86% | 99.18% |
| 六视角投影 mIoU | 88.51% | 97.06% |
| 六视角投影准确率 | 97.79% | 99.65% |
| 体素 mIoU | 79.70% | 91.69% |
| 隐藏表面 mIoU | 71.67% | 92.04% |
| 表面小部件召回率 | 57.03% | 91.25% |
| 边界 F1 | 30.71% | 49.31% |
| 孤立错误面积比例（越小越好） | 1.276% | 0.348% |

小部件定义为占该对象总标注表面积不到 1% 的部件；没有小部件的对象不参与该项平均。

**11/128** 个对象低于 50%。高整体面积准确率不能掩盖小部件丢失。

## 吉他及历史案例

| 对象 | DiT 表面 mIoU | VAE 表面 mIoU | 角色 |
| --- | ---: | ---: | --- |
| 吉他 `251c8125765149c0bd46b3a1a51ff4b6` | 5.28% | 39.70% | test，60 部件 |
| 吉他 `d1d58f05c346470e9805612d562e9dde` | 10.55% | 38.10% | test，54 部件 |
| 椅子 `007d2949e5b0450c995c54809b43af0f` | 91.44% | 98.11% | train 诊断 |
| 床 `11c88bc30d37479281c30cc49d25084a` | 76.42% | 98.17% | train 诊断 |
| 沙发 `141329918e4945ed82d0f48ba5903b8f` | 89.22% | 99.31% | train 诊断 |

第一把吉他：DiT 将占总表面 56.72% 的编号 60 琴身几乎完全错标，琴身召回只有
**0.35%**，对应 VAE 为 **88.77%**。DiT 有 **46/60** 个部件召回为 0，VAE 是 19 个。
该对象 shape 条件匹配率为 99.78%，不能把失败简单归因于 shape 条件大量缺失。

第二把吉他：琴身编号 7 召回 **97.33%**，主体保留，但 **40/54** 个部件完全漏掉，
因此表面准确率仍有 78.50%，mIoU 却只有 10.55%。其 shape 条件匹配率为 100%。

人工检查三排图：椅子座面、床垫/床头/枕头、沙发主体大体保留，但 DiT 的细部件、
交界处和隐藏面有额外错标。三项 train 诊断不计入 128 test 汇总。

目前证据支持“DiT 条件生成还有明显差距”，但尚未在 DiT 上运行编号置换消融，
不能直接断言所有失败均由编号偏向导致。训练配置确实没有 DiT 原标签置换重编码增强；
新 VAE 经编号置换训练并不自动使 DiT 获得同样的不变性。
